# Codex instructions

This repository is a Shaiya private-server development workspace.

- Inspect existing files before making changes; do not assume a particular Shaiya episode, database schema, server distribution, or programming language.
- Explain proposed changes and keep changes small and reviewable.
- Never add real credentials, production database exports, proprietary binaries, or third-party copyrighted code without authorization.
- Prefer configuration examples, migrations, documentation, and tests.
- Do not run destructive SQL or overwrite server configurations without explicit approval.
- Ask for the server version, database engine, and runtime before generating deployment-specific commands.
- Document how to test each change and avoid claiming tests passed unless executed.
