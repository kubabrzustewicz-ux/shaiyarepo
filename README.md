# Shaiya Private Server Development

Development workspace for Shaiya server configuration, database scripts, utilities, and documentation.

## Layout
- `server/` — server configuration templates and scripts
- `database/` — versioned migrations and SQL queries
- `tools/` — supporting utilities
- `docs/` — setup and operations notes
- `tests/` — automated checks

## Getting started
1. Clone the repository.
2. Read `AGENTS.md` for Codex instructions.
3. Add only files you are authorized to use. Never commit live credentials, database dumps containing personal data, or proprietary binaries.

Server runtime, database engine, and implementation language are not yet selected.
